How to Use Your iPhone as an LG webOS TV Remote

Click Cast lets you use your iPhone as a remote for a compatible LG webOS TV on your home network. Pairing can use a code shown on the TV or an on-TV authorization prompt, depending on the model.

Setup steps

  1. Turn on your LG webOS TV and connect it and your iPhone to the same home network. Avoid guest Wi-Fi and device isolation.
  2. Open Click Cast and allow Local Network access. If you denied it earlier, enable it for Click Cast in iPhone Settings.
  3. Open the device list and select your LG TV.
  4. If the TV shows a pairing code, enter it in the app. If it shows an Allow prompt instead, approve the request on the TV. Follow the instructions shown for your model; keep codes private.
  5. After connecting, try navigation and volume. On compatible models, use the Apps tab to launch an application or the keyboard to send text to an active TV text field. The Input button opens the TV’s input selection menu.

Troubleshooting and common questions

My LG TV does not appear

Check that the TV is on, both devices are on the same home network, and Click Cast has Local Network permission. A guest network may block discovery. Some LG models have a setting for mobile or network control; check your model’s manual because the name and location vary. Scan again after fixing the network or permission.

Pairing is waiting for permission

Look at the TV screen for a code or Allow prompt. Enter the current code in Click Cast, or approve the request on the TV. If you rejected the request or it timed out, start a new pairing attempt. A previously paired TV may ask you to authorize the app again.

Can I pair without the physical remote?

A compatible TV that displays a pairing code may let you enter that code on your iPhone without using the physical remote. Models that show an Allow prompt still need a way to approve it on the TV. The TV must already be on and connected to the network.

The keyboard sends text, but nothing appears

First focus a text field in an application on the TV. Text input availability varies by model and TV application; some fields do not accept remote text. Try an ordinary search field. Do not treat every field, including password fields, as supported.

Will every LG television work?

No. This guide is for compatible LG webOS TVs with network control support, not every LG television. Controls depend on the model and firmware. If a button is unavailable, use another supported control rather than repeatedly pairing.

Remote control and casting are different

Remote pairing authorizes TV controls. Sending photos or videos uses DLNA and requires a compatible media renderer and separate TV permissions. It is not screen mirroring. If the remote works but casting does not, see the casting troubleshooting steps rather than removing a working remote pairing.
